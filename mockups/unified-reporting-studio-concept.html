A few number rules are yours to decide (not mine)

These don’t change the plan — I’ll ask them when you pick a direction. The dashboard will never guess them.

  1. Trend targets: is the SPI/CPI reference line exactly 1.00, and the CPLI target 100%?
  2. Change colours: rising CPI = good, rising delay = bad — and how big a weekly change turns a tile amber vs red?
  3. Score-gauge zones: what score is green / amber / red for Float Health and CPLI?
  4. “Needs attention” order: use each feature’s own severity, or one shared ranking across features?
  5. Discipline gap: rank by the raw plan−actual gap, or weight it by each discipline’s cost weight?
  6. Overall verdict rule (only if you want the single On-track/At-risk/Critical label): which domains count, and how is a not-run domain handled?
